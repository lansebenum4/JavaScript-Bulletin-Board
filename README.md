# JavaScript-Bulletin-Board
A simple command-line noticeboard written in Java. Team captains can post notices, and the program lets you view, count and search them from a numbered menu.
Features
Post a notice under a captain's name (the board holds up to 10 notices)
Print all notices, oldest first or newest first
Show how many notices have been posted
Find every notice posted by a given captain (not case-sensitive)
Count the total number of digits across all notice messages
Search notices for a word, with or without matching case
